# Screenshots

The repository `README.md` references the images in this folder. To populate the
gallery, drop PNGs here using these **exact** filenames:

| File | What to capture |
|------|-----------------|
| `miller-light.png` | Main window in **Miller Columns** view, **light** theme, desktop width (~1100 px). A few columns deep with a file selected. |
| `miller-dark.png`  | Same scene, **dark** theme. |
| `preview.png`      | A file selected so the **docked preview pane** is visible — ideally a code file showing syntax highlighting (or an image/video). |
| `mobile.png`       | The window **narrowed** until the sidebar collapses into the adaptive overlay (the "mobile" layout). |

Tips:
- Keep the widths consistent (~1100 px for the desktop shots) so the 2×2 grid lines up.
- PNG preferred; trim window shadows if your OS adds large ones.
- On GNOME: `Screenshot` tool (PrintScreen) → window capture. On macOS: `Cmd+Shift+4` then Space to grab the window.

Once the files are here, the gallery in the top-level `README.md` renders automatically.
